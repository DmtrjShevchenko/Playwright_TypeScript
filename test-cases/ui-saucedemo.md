# UI тест-кейси — SauceDemo

**Система:** https://www.saucedemo.com
**Браузер:** Chromium (Desktop Chrome)
**Тестові дані:** пароль для всіх користувачів — `secret_sauce`

**Загальна передумова для всіх кейсів, крім логіну:** користувач залогінений як `standard_user` і знаходиться на сторінці каталогу `/inventory.html`. Кошик на старті порожній: кожен тест запускається в новому контексті браузера.

---

## Логін

### UI-LOGIN-01 · Успішний логін `standard_user`
- **Тип / Пріоритет:** Позитивний / P1
- **Передумова:** відкрита сторінка логіну `/`.

| # | Крок | Очікуваний результат |
|---|---|---|
| 1 | Ввести логін `standard_user`, пароль `secret_sauce` | — |
| 2 | Натиснути **Login** | Відкривається `/inventory.html`, заголовок сторінки — **Products** |

### UI-LOGIN-02 · Логін заблокованого користувача
- **Тип / Пріоритет:** Негативний / P1
- **Передумова:** відкрита сторінка логіну `/`.

| # | Крок | Очікуваний результат |
|---|---|---|
| 1 | Ввести логін `locked_out_user`, пароль `secret_sauce` | — |
| 2 | Натиснути **Login** | Помилка: `Epic sadface: Sorry, this user has been locked out.` Переходу на каталог немає |

### UI-LOGIN-03 · Логін з невірним паролем
- **Тип / Пріоритет:** Негативний / P1
- **Передумова:** відкрита сторінка логіну `/`.

| # | Крок | Очікуваний результат |
|---|---|---|
| 1 | Ввести логін `standard_user`, пароль `wrong_password` | — |
| 2 | Натиснути **Login** | Помилка: `Epic sadface: Username and password do not match any user in this service`. Переходу на каталог немає |

## Чекаут

**Передумова для обох кейсів:** у кошик додано **Sauce Labs Backpack** ($29.99) і **Sauce Labs Onesie** ($7.99), відкрита сторінка кошика.

### UI-CHK-01 · Чекаут: успішне оформлення замовлення
- **Тип / Пріоритет:** Позитивний / P1

| # | Крок | Очікуваний результат |
|---|---|---|
| 1 | Натиснути **Checkout** | Відкривається `/checkout-step-one.html` |
| 2 | Заповнити First Name `Test`, Last Name `User`, Postal Code `01001`, натиснути **Continue** | Відкривається `/checkout-step-two.html`, у замовленні Backpack і Onesie |
| 3 | Перевірити суми | Item total = **$37.98** (сума цін товарів); Tax > 0; Total = Item total + Tax |
| 4 | Натиснути **Finish** | Відкривається `/checkout-complete.html`, заголовок **Thank you for your order!**, лічильник кошика зник |

> Суми порівнюються в центах, щоб уникнути похибки дробових чисел.
